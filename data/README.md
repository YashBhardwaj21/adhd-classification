# Data

Raw ADHD-200 imaging data are not distributed with this repository.

The experiments use derived functional-connectivity representations, graph objects, volumetric inputs, manifests, and other intermediate datasets generated from ADHD-200.

These data can be large and may have redistribution restrictions. Reproduction therefore requires obtaining the corresponding ADHD-200 data independently and configuring the notebooks for local paths.

Lightweight manifests, configuration files, result tables, and selected figures are included where appropriate.

Large raw files and generated arrays are excluded.
